# Текстовое описание задания:
Космические бои могут проводить только зарегистрированные пользователи. Космические бои проводятся как в рамках турниров, 
либо между любыми пользователями по договоренности.
Можно посмотреть список будущих турниров, подать заявку на участие в турнире, посмотреть результаты проходящих турниров, уже прошедших.
Участники боев получают уведомлении о приглашении на турнир, решение по заявке на участие в турнире, о завершении боя, 
о скором начале боя. Игорок может посмотреть прошедший бой. За места в турнире участники получают рейтинговые очки.
Каждый пользователь может организовать свой турнир. Турниры получают рейтинг, который рассчитывается на основе рейтингов 
ее участников. Турнир может быть регулярным, тогда рейтинг его накапливается.
Игрок принимает участие в игре посредством программы, которая загружается в специальное приложение Агент.

## Для успешного решения задачи необходимо:

1. Определить набор микросервисов и веб-приложений и отобразить их на диаграмме/наборе диаграмм.
2. Определить направления обмена сообщениями и Endpoints для каждого микросервиса и приложения.
3. Определить узкие места и потенциальные проблемы масштабирования приложения и способы их решения.
4. Определить компоненты, к которым чаще всего будут меняться требования и способы выполнения OCP для них.
5. Сделать текстовые пояснения к созданному решению.
Все документы, составляющие решение выложить в git.

## Схема микросервисов
![alt text](https://github.com/Ks-Ksenia/quadratic_equation/blob/ffefb011be4ea161d022e538a3c5ad3ce34d9784/schema.png?raw=true)


Игрок взаимодействует с игрой через клиентский графический интерфейс.
Клиентское приложение взаимодействует с серверной частью системы через протокол HTTPS, используя json-схемы.
Серверная часть состоит из микросервисов:

- Сервис авторизации
- Сервис турниров и рейтингов
- Сервис рассылок сообщений

### Сервис авторизации
Сервис авторизации позволяет выполнять регистрацию пользователя, аутентификацию пользователя, смену пароля пользователя.

### Сервис турниров и рейтингов
Сервис позволяет взаимодействовать с сущностью "Турнир" и "Рейтинг" по всем CRUD-операциям.

### Сервис рассылок сообщений
Сервис организовывает массовую рассылку сообщений по турнирам, а так же рассылку при взаимодействии с сервисом авторизации.


## Проблемы
1. Единственный сервис турниров и рейтингов, что при наплыве пользователь приведёт к уменьшению пропускной способности и 
    снижению скорости работы даже для игроков, что уже в игре.
    ### Решение:
- Сделать несколько инстансов приложения. И перенаправлять пользователя к менее горящему.
- Кэширование результатов рейтингов.
2. Отказ какой-либо из БД.

    ### Решение:
- Реализовать репликацию для БД сервиса авторизации и турниров.
3. Нехватка мест на какой-либо из БД.

    ### Решение:
- Купить больше места на диске.
- Если уже невозможно покупать место на диске, то реализовать шардирование.
